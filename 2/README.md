# Лабораторная работа #2: Основы обработки цифровых изображений/сжатие изображений

**Тема:** Построение и эквализация гистограммы изображения, линейное контрастирование и реализация низкочастотных (сглаживающих) фильтров.

## 1. Цель работы
Разработка графического приложения на языке Java для реализации и сравнительного анализа базовых алгоритмов обработки изображений: методов повышения контраста (линейное растяжение, эквализация) и методов подавления шума.

## 2. Описание программы
Приложение **ImageProcessorApp** представляет собой инструмент для визуального сравнения результатов работы различных алгоритмов обработки растровых изображений. Программа позволяет загружать изображения и отображать результаты обработки в трех режимах, разделенных по вкладкам.

**Основные возможности:**
*   Построение и визуализация гистограмм яркости изображений.
*   Сравнение методов повышения контраста.
*   Сравнение подходов к цветовой коррекции (в пространствах RGB и HSV).
*   Применение низкочастотных фильтров с различными ядрами.

## 3. Интерфейс приложения
Графический интерфейс реализован с использованием библиотеки Swing и организован в виде вкладок (`JTabbedPane`):

1.  **Вкладка "Повышение контраста":** Демонстрирует разницу между линейным контрастированием и глобальной эквализацией гистограммы. Под каждым изображением строится график распределения яркости.
2.  **Вкладка "Цветная эквализация":** Сравнивает поканальную обработку (RGB) с обработкой яркостной компоненты (HSV).
3.  **Вкладка "Низкочастотные фильтры":** Позволяет выбирать и применять различные фильтры размытия к исходному изображению.

## 4. Реализованные алгоритмы

### 4.1. Повышение контраста
*   **Линейное контрастирование (Linear Contrast Stretching):**
    Метод растягивает диапазон яркости изображения на весь доступный интервал [0, 255].
    *   *Формула:* $P_{new} = (P_{old} - P_{min}) \cdot \frac{255}{P_{max} - P_{min}}$
*   **Эквализация гистограммы (Histogram Equalization):**
    Нелинейный метод, который стремится сделать распределение яркости равномерным, используя кумулятивную функцию распределения (CDF). Позволяет максимально выявить детали в тени и свету.

### 4.2. Цветовая обработка
*   **RGB-эквализация:** Алгоритм применяется независимо к каждому цветовому каналу (Red, Green, Blue).
    *   *Недостаток:* Нарушает цветовой баланс, приводя к появлению неестественных оттенков.
    
В результате обработки фото, на гистограмме возникли "выбросы": наблюдается характерная структура с резкими пиками, разделенными нулевыми значениями (пустотами). Данное явление называется «эффектом гребня» и обусловлено тем, что исходное изображение имело узкий динамический диапазон, поэтому в процессе эквализации алгоритм «раздвинул» эти плотно сгруппированные оттенки на весь диапазон [0, 255] для повышения контраста. Так как значения яркости являются целыми числами, промежуточные оттенки между «раздвинутыми» пиками не могут быть синтезированы из ниоткуда, в результате чего образуются провалы (яркости, у которых количество пикселей равно 0).
*   **HSV-эквализация:** Изображение конвертируется в пространство HSV. Эквализация применяется только к каналу **Value** (Яркость), после чего изображение конвертируется обратно в RGB.
    *   *Преимущество:* Сохраняет исходные цветовые тона и насыщенность, изменяя только контраст. Реализована с точностью 256 уровней для предотвращения эффекта постеризации.

### 4.3. Пространственная фильтрация (Сглаживание)
Реализована операция свертки (Convolution) с обработкой краев изображения методом **Clamping** (дублирование граничных пикселей), что исключает появление черных рамок по краям изображения.

*   **Box Blur (3x3):** Усредняющий фильтр. Каждому пикселю присваивается среднее значение его соседей.
*   **Gaussian Blur (3x3, 5x5):** Фильтр Гаусса. Использует взвешенное усреднение (центральные пиксели имеют больший вес), что дает более мягкое и качественное размытие.
*   **Strong Box Blur (11x11):** Фильтр с большим ядром для демонстрации эффекта размытия на изображениях высокого разрешения.

## 5. Техническая реализация
*   **Язык:** Java (JDK 8+).
*   **Библиотеки:** Стандартные `javax.swing` и `java.awt`. Сторонние библиотеки обработки изображений (OpenCV и др.) не использовались.
*   **Работа с данными:** Прямая манипуляция массивами пикселей через `BufferedImage`.
*   **Математика:**
    *   Ручной расчет гистограмм и таблиц подстановки (LUT).
    *   Ручная реализация свертки (Convolution) для корректной обработки границ изображения.

## 6. Сравнительный анализ методов

| Метод | Описание результата | Применение |
| :--- | :--- | :--- |
| **Линейное контрастирование** | Сохраняет естественность изображения. Неэффективно, если в изображении уже присутствуют точки с яркостью 0 и 255 (полный динамический диапазон). | Базовая цветокоррекция фото, устранение "блеклости". |
| **Эквализация (RGB)** | Дает максимальный контраст, но приводит к сильному искажению цветов и изменению оттенков (нарушение баланса белого). | Технический анализ, обработка полутоновых (черно-белых) изображений. |
| **Эквализация (HSV)** | Высокий контраст с полным сохранением естественных цветов и оттенков. | Художественная обработка, улучшение пейзажных снимков. |
| **Фильтр Гаусса** | Эффективное удаление шума. Сохраняет контуры объектов лучше, чем обычное усреднение (Box Blur). | Предварительная обработка, шумоподавление. |

## 7. Заключение
В ходе выполнения работы было разработано приложение, демонстрирующее фундаментальные принципы обработки цифровых изображений.

Сравнение методов показало, что:
1.  Для цветных изображений более корректным методом повышения контраста является работа в пространстве **HSV**, так как она не искажает цветовую информацию.
2.  При реализации фильтров размытия критически важна корректная обработка граничных пикселей (метод **Clamping**), чтобы избежать артефактов на краях изображения.
