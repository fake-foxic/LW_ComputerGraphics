# Отчет по лабораторной работе №1: Цветовые модели

**Тема:** Разработка приложения на языке Java для конвертации цветов из одной цветовой модели в другую.

**Название программы:** ColorConverterApp

## 1. Цель работы
Изучить цветовые модели и преобразования между ними.
Создать приложение, позволяющее пользователю выбирать, а затем интерактивно менять цвет, показывая при этом его составляющие в трех моделях одновременно (RGB, CMYK и HSV).

## 2. Постановка задачи
Необходимо разработать приложение, удовлетворяющее следующим требованиям:
1.  Поддержка трех цветовых моделей:
    *   **RGB** (Red, Green, Blue) — диапазон значений 0–255.
    *   **CMYK** (Cyan, Magenta, Yellow, Key) — диапазон значений 0–100.
    *   **HSV** (Hue, Saturation, Value) — Hue 0–360, Sat/Val 0–100.
2.  Реализация трех способов задания цвета:
    *   Интерактивное изменение через ползунки.
    *   Точный ввод числовых значений через текстовые поля.
    *   Выбор цвета из предоставленной палитры.
3.  Обеспечение синхронизации моделей: при изменении параметров в одной модели должны автоматически пересчитываться значения в двух других.
4.  Корректная обработка пользовательского ввода.

## 3. Реализация

### 3.1. Логика работы и обработка событий
В программе реализована событийно-ориентированная модель. Для синхронизации компонентов использованы слушатели:
*   `ChangeListener` — отслеживает перемещение ползунков в реальном времени.
*   `ActionListener` — обрабатывает нажатие клавиши Enter в текстовых полях.
*   `FocusListener` — применяет введенное значение при потере фокуса текстовым полем.

**Механизм защиты от зацикливания:**
Так как модели зависимы друг от друга (изменение RGB меняет CMYK, изменение CMYK меняет RGB), реализован флаг блокировки `isUpdating`. Он предотвращает рекурсивный вызов методов обновления при программном изменении значений компонентов.

### 3.2. Алгоритмы конвертации
Математическое ядро программы обеспечивает перевод значений:

1.  **RGB ↔ HSV:**
    Используются стандартные методы библиотеки AWT: `Color.RGBtoHSB` для прямого преобразования и `Color.HSBtoRGB` для обратного.

2.  **RGB ↔ CMYK:**
    Реализован алгоритм пересчета.
    *   *RGB → CMYK:* Вычисляется компонента Black (Key) как `1 - max(R, G, B)`, после чего рассчитываются остальные каналы с нормализацией.
    *   *CMYK → RGB:* Обратное преобразование с учетом составляющей черного.

    *Особенность реализации:* Для устранения погрешностей вычислений с плавающей точкой применено математическое округление (`Math.round`). Это позволяет избежать ситуаций, когда значение 20% преобразуется в 19.999% и отображается как 19.

## 4. Руководство пользователя
1.  **Запуск:** Приложение запускается через главный класс `ColorConverterApp`.
2.  **Использование слайдеров:** Перемещение ползунка любого цветового канала мгновенно обновляет итоговый цвет и значения во всех остальных полях.
3.  **Ввод значений:** Допускается ручной ввод целых чисел в текстовые поля. Ввод применяется по нажатию Enter или клику вне поля. При вводе некорректных данных (выход за границы диапазона, буквы) значение автоматически корректируется или сбрасывается.
4.  **Палитра:** Кнопка "Выбрать из палитры..." открывает окно с набором предустановленных цветов.

## 5. Вывод
В ходе лабораторной работы было разработано функциональное приложение на языке Java. Приложение корректно выполняет поставленную задачу синхронной конвертации цветовых моделей RGB, CMYK и HSV.
