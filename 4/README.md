# Лабораторная работа № 4: Алгоритмы отсечения (Liang-Barsky & Cyrus-Beck)

**Тема:** Реализация и визуализация алгоритмов отсечения отрезков прямоугольным окном и произвольным выпуклым многоугольником на Java.

## Описание проекта

Данное приложение демонстрирует работу параметрических алгоритмов отсечения в компьютерной графике. Программа предоставляет графический интерфейс для загрузки данных об отрезках, визуализации сцены и интерактивного задания области отсечения.

Приложение позволяет наглядно сравнить исходные отрезки и их видимые части, отсеченные по границам заданной области.

---

## Реализованные алгоритмы

### 1. Алгоритм Лианга-Барски (Liang-Barsky)
*   **Тип отсекателя:** Прямоугольное окно со сторонами, параллельными осям координат.
*   **Принцип работы:** Использует параметрическое представление прямой. Алгоритм сводит задачу к решению системы из 4-х неравенств для параметра `t`. Вычисляются значения входа и выхода луча в область окна.
*   **Преимущества:** Высокая производительность, так как вычисляет пересечения только для потенциально видимых отрезков.

### 2. Алгоритм Сайруса-Бека (Cyrus-Beck)
*   **Тип отсекателя:** Произвольный **выпуклый** многоугольник.
*   **Принцип работы:** Обобщение подхода Лианга-Барски. Использует векторы нормали к сторонам многоугольника.
    *   Для каждого ребра вычисляется скалярное произведение вектора направления отрезка и внутренней нормали.
    *   Знак произведения определяет, входит луч в полуплоскость или выходит из нее.
*   **Особенность реализации:** Реализован алгоритм **автоматической ориентации нормалей**. Программа находит геометрический центр многоугольника и принудительно разворачивает все нормали внутрь. Это позволяет пользователю рисовать многоугольник в любом направлении (по часовой стрелке или против) без ошибок.

---

## Функциональные возможности

1.  **Два режима работы:**
    *   Отсечение прямоугольником (координаты берутся из входного файла).
    *   Отсечение многоугольником (рисуется пользователем вручную).
2.  **Интерактивное рисование:**
    *   Пользователь может создать отсекающую область любой формы (треугольник, ромб, n-угольник) с помощью мыши.
    *   **ЛКМ (Левая кнопка)** — поставить вершину.
    *   **ПКМ (Правая кнопка)** — замкнуть фигуру и выполнить отсечение.
3.  **Управление холстом:**
    *   Масштабирование (Zoom) колесиком мыши.
    *   Перемещение (Pan) зажатой левой кнопкой мыши.
4.  **Валидация:** Проверка многоугольника на выпуклость перед выполнением алгоритма Сайруса-Бека.

## Визуализация и Легенда

На графике используется цветовая кодировка для различия элементов:

| Элемент | Цвет / Стиль | Описание |
| :--- | :--- | :--- |
| **Исходный отрезок** | ⬜ Серый пунктир | Полная длина отрезка, заданная во входных данных. |
| **Видимая часть** | 🔴 **Жирный красный** | Результат работы алгоритма (часть отрезка внутри области). |
| **Окно (Liang-Barsky)** | 🟦 Синий (полупрозрачный) | Область отсечения для прямоугольного режима. |
| **Полигон (Cyrus-Beck)**| 🟩 Зеленый (полупрозрачный)| Область отсечения для режима многоугольника. |
| **Подписи** | ⚫ Текст (L1, L2...) | Идентификатор отрезка для сопоставления с логом. |

## Формат входных данных

Программа принимает текстовые файлы (`.txt`), в которых данные расположены построчно в следующем порядке:

1.  **Строка 1:** Целое число `N` — количество отрезков.
2.  **Строки 2...N+1:** Координаты отрезков в формате `x1 y1 x2 y2` (разделитель пробел).
3.  **Последняя строка:** Координаты прямоугольного окна `x_min y_min x_max y_max`.

> **Примечание:** Последняя строка файла используется только для алгоритма Лианга-Барски. В режиме выпуклого многоугольника область отсечения задается графически пользователем.

## Тестирование

### Тест 1: Прямоугольное окно (Liang-Barsky)
Загрузка файла с прямоугольником.
*   Отрезки, полностью лежащие внутри, окрашиваются в красный целиком.
*   Отрезки, пересекающие границы, обрезаются строго по синей рамке.
*   Отрезки снаружи остаются серым пунктиром.

### Тест 2: Треугольник (Cyrus-Beck)
Пользователь рисует треугольник вокруг центра координат.
*   Горизонтальные и вертикальные линии обрезаются под углом, соответствующим сторонам треугольника.
*   Проверяется корректность работы автоматического расчета нормалей (отсечение работает верно независимо от порядка расстановки точек треугольника).

### Тест 3: Невыпуклый многоугольник
При попытке нарисовать "звезду" или "вогнутую" фигуру программа выводит предупреждение о том, что многоугольник не выпуклый. Это демонстрирует ограничение математического аппарата алгоритма Сайруса-Бека.

## Инструкция по выполнению
    1. Нажмите кнопку загрузки файла и выберите `.txt` файл.
    2. Выберите алгоритм переключателем слева.
    3. Если выбран **Сайрус-Бек**: нажмите кнопку рисования, расставьте точки левой кнопкой мыши и завершите правой кнопкой.
